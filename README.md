# Orbit — лабораторная работа №5

Фронтенд-каталог типов орбит. Интерфейс состоит из двух страниц: ленты и плитки. Данные для страниц берутся из локального массива **mockOrbits**; backend для отображения каталога не требуется.

## Страницы приложения

### Лента — /

Страница показывает один тип орбиты за раз.

- Отображаются название, описание, высота, наклонение и число отметок «Нравится».
- Фоновое видео запускается автоматически без звука. Если видео не загрузилось, показывается изображение по умолчанию.
- Кнопка **«Ещё ↓»** раскрывает описание полностью; **«Скрыть ↑»** сворачивает его.
- Кнопка с сердцем ставит или снимает отметку «Нравится». Состояние лайка хранится отдельно для каждой орбиты.
- Кнопка со стрелкой **→** открывает следующую орбиту в ленте.
- В нижней панели пункт **«Лента»** открывает эту страницу.

### Плитка — /orbit-type/grid

Страница показывает карточки орбит и позволяет отфильтровать их по высоте.

- Ползунок **«Максимальная высота, км»** задаёт предел фильтра от 0 до 40 000 км с шагом 100 км. Текущее значение отображается рядом в километрах.
- Кнопка **«Показать»** применяет выбранный предел. В списке остаются орбиты, высота которых не превышает заданное значение.
- В карточке показаны изображение по умолчанию, название, высота, наклонение и число лайков.
- Нажатие на карточку открывает соответствующую орбиту в ленте.
- Кнопка **«Удалить»** убирает карточку из текущего списка.
- Статус карточки отображается как **«Опубликован»**.
- В нижней панели пункт **«Плитка»** открывает эту страницу.

## Нижняя навигация

- **Лента** — переход к ленте орбит.
- **Плитка** — переход к карточкам орбит.
- **Добавление** и **Войти** показаны в панели, но в этой версии неактивны.

## Запуск

Установите зависимости и запустите Vite:

    npm install
    npm run dev

Приложение откроется по адресу, указанному Vite в терминале (обычно http://localhost:5173).
