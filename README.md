# Orbit — лабораторная работа №6

Фронтенд-каталог типов орбит. В приложении четыре страницы: лента, добавление типа орбиты, плитка и вход. Состояние фильтра, данных орбит и авторизации хранится в Redux Toolkit. Гости могут просматривать каталог; если backend недоступен, для чтения используются данные **mockOrbits**.

## Страницы приложения

### Лента — /

Страница показывает один тип орбиты за раз.

- Отображаются название, описание, высота, наклонение и число отметок «Нравится».
- Фоновое видео запускается автоматически без звука. Если видео не загрузилось, показывается изображение по умолчанию.
- Кнопка **«Ещё ↓»** раскрывает описание полностью; **«Скрыть ↑»** сворачивает его.
- Вошедший пользователь может поставить или снять лайк. Состояние лайка и число отметок приходят от backend.
- Кнопка со стрелкой **→** запрашивает следующую орбиту у backend; при гостевом offline-режиме переключает локальные mock-записи.
- В нижней панели пункт **«Лента»** открывает эту страницу.

### Плитка — /orbit-type/grid

Страница показывает карточки орбит и позволяет отфильтровать их по высоте.

- Ползунок **«Максимальная высота, км»** задаёт предел фильтра от 0 до 40 000 км с шагом 100 км. Текущее значение отображается рядом в километрах.
- Кнопка **«Показать»** применяет выбранный предел. В списке остаются орбиты, высота которых не превышает заданное значение.
- В карточке показаны изображение орбиты из backend/MinIO (или изображение по умолчанию), название, высота, наклонение, число лайков и статус публикации.
- Нажатие на карточку открывает соответствующую орбиту в ленте.
- Вошедший пользователь может удалить собственную опубликованную орбиту кнопкой **«Удалить»**.
- Поле фильтра хранит выбранное значение при переходах по страницам; кнопка **«Показать»** отправляет его backend.
- В нижней панели пункт **«Плитка»** открывает эту страницу.

### Добавление типа орбиты

Страница доступна после входа. На первом шаге пользователь вводит название, выбирает фотографию и видео и видит их предпросмотр, затем нажимает **«Далее»**. На втором шаге он может заполнить описание, высоту в километрах и наклонение в градусах; все три поля необязательны. Кнопка **«Опубликовать»** сохраняет карточку даже если они пустые. Выбор файлов загружает черновик; публикация отправляет параметры отдельно.

### Авторизация пользователя

Страница предназначена для входа в существующий аккаунт. Пользователь заполняет поля **«Электронная почта»** и **«Пароль»**, затем нажимает **«Войти»**. После входа показываются имя и почта пользователя, а также кнопка **«Выйти»**. Регистрация в этой лабораторной не реализуется.

## Нижняя навигация

- **Лента** — переход к ленте орбит.
- **Добавление** — переход к форме создания (гостя перенаправляет на вход).
- **Плитка** — переход к карточкам и фильтру орбит.
- **Войти** — открывает вход; после авторизации пункт меняется на **«Выйти»**.

## Redux и backend

- Redux Toolkit содержит состояние пользователя, список орбит, данные ленты, черновик, фильтр, ошибки и индикатор загрузки.
- Во время запросов показывается индикатор загрузки, который блокирует действия до ответа backend.
- Запросы семи методов типов орбит выполняются сгенерированным Axios-клиентом через `createAsyncThunk`: список, лента, черновик, создание черновика, публикация, удаление и лайк.
- Вход и выход выполняются отдельными Axios-запросами; после ответа приложение вручную обновляет состояние пользователя в Redux.
- Все запросы отправляются с cookie-сессией. Для медиафайлов Vite проксирует `/minio` на локальный MinIO.
- Чтобы получить актуальный API-клиент из Swagger backend, запустите backend и выполните `npm run generate:api`. Скрипт читает `http://localhost:3000/api-json`; если backend выключен, берёт сохранённую спецификацию `src/api/openapi.snapshot.json`.

## Запуск

Установите зависимости и запустите Vite:

    npm install
    npm run dev

Backend для гостевого просмотра не обязателен. Для входа, добавления, удаления и лайков запустите backend и его сервисы.

Приложение откроется по адресу, указанному Vite в терминале (обычно http://localhost:5173).
